Virtual Lab

Explore science by changing variables, running simulations and analysing your results. Built with plain HTML, CSS and JavaScript.

Made for learning

Every lab includes an aim, background theory, adjustable controls and results. These are educational simulations, not substitutes for supervised real-world laboratory procedures.

Run locally with python3 serve.py. Deploy by pushing to main and selecting GitHub Actions in Settings → Pages.
